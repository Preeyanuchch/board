⚙️ ตั้งค่า Google Apps Script
ทำครั้งเดียว — บันทึกใน localStorage ของ browser
1สร้าง Google Sheet ใหม่
ไปที่ sheets.new → ตั้งชื่อไฟล์ตามต้องการ (เช่น "Live Quiz Board")
2เปิด Apps Script
เมนู Extensions → Apps Script → ลบโค้ดเดิมออกทั้งหมด → วางโค้ดจากไฟล์ Code.gs ที่ได้รับ → กด Save
3Deploy เป็น Web App
Deploy → New deployment → Type: Web app
Execute as: Me
Who has access: Anyone
→ Deploy → อนุญาต permission → คัดลอก Web app URL
